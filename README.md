### ft_scanf (variadic functions)
Man scanf says: The scanf() family of functions scans input according to a format, as described below.  This format may contain conversion specifiers; the results from such conversions, if any, are stored through the pointer arguments.  The scanf() function reads input from the standard input stream
stdin, fscanf() reads input from the stream pointer stream, and sscanf() reads its input from the character string pointed to by s.
